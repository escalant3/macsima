# Feature parity with wxMaxima

Where Macsima stands against wxMaxima, as of Phase 2 (2026-10-18), updated during Phase 3. The first table follows the "What the GUI owns" table in `docs/BOOTSTRAP.md`, row by row. The second lists what turned up along the way. Status is done, partial or missing. Phase is where the gap belongs, following BOOTSTRAP.md's MVP column and roadmap. File-format details are in `docs/WXMX_COMPAT.md`.

## The GUI table from BOOTSTRAP.md

| Area | wxMaxima | Macsima now | Status | Phase |
| --- | --- | --- | --- | --- |
| Document model | Title, section, subsection, text and code cells (plus deeper headings, images, page breaks), `.wxmx` and `.wxm` | Every `.wxmx` cell kind in the model. The editor creates code, text, title, section, subsection and image cells (Insert Image…). Deeper headings, page breaks (a dashed rule) and image cells (caption and image, `.svgz` too) show (Phase 3 step 8); unknown cells are placeholders, kept and saved back. `.wxmx` read and write; `.wxm` in WorksheetKit, used for the clipboard (opening `.wxm` files: step 13). | partial | `.wxm` files: 3 (step 13) |
| Evaluation queue | Splits cells into statements, `;` versus `$`, `:lisp` and `to_lisp()`, adds a missing terminator, one statement at a time | All of it, through MaximaKit (Phase 1). Cells run in order; Cmd+R evaluates all. | done | |
| Error handling | Optionally aborts on error, marks the failing statement and spot in the editor | The rest of the cell is skipped and the error shows with its text. The failing statement and the syntax error's spot are marked in the editor; see Error marker below. No abort-on-error setting yet. | partial | setting: 3 (step 14) |
| Questions and debugger | Answer cells for questions; the `(dbm:N)` debugger and LDB are special cases | Questions show inline with an answer field, and answers are saved the way wxMaxima saves them. The debugger prompt shows as a question; no debugger UI, no LDB. | partial | 3 |

| Plots | PNG or SVG from `img`, animations from `slide` | PNG and SVG plots (`wxplot_usesvg:true`), `wxdraw2d` (`wxdraw3d` not tried), read into the document at once; animations with play, pause and a frame slider (Phase 3 step 8) | done | |
| Autocomplete | `wxxml-symbols` and the user's own definitions | Cell › Complete Word (Esc, or wxMaxima's Ctrl+Space when the input-source switcher doesn't take it) and Show Template (Ctrl+Shift+Space) in code cells: Maxima's names, wxMaxima's 2029 built-in templates (`builtin_commands.txt`, copied), and the names and `f(x) :=` / `define` definitions in the worksheet's code cells, marked "worksheet". One match is inserted at once, several open a list that narrows as you type (Up/Down, Return or Tab, Esc). A template's first `<argument>` is selected; Tab and Shift+Tab step through them, shown with a blue background. One undo step (Phase 3 step 9, `complete-basics` key script). Not done: file names after `load("`, `demo` files and ezunits units, wxMaxima's user file of extra symbols, Esc-sequences for Greek letters (see Greek letters with Esc below), completing as you type | partial | file names, units, as-you-type: later |
| Variables and status | Watch panel, status bar, CPU polling | Variables panel in the sidebar (View › Variables, ⌘⌥2): type names or Add All (Maxima's `values`); values in linear form, refreshed after each evaluation in one query (`macsima-values` in macsima.lisp; wxMaxima sends one per variable), functions show their definition, unbound names "no value", values over 4000 characters cut; Copy Value, Stop Watching. The list is saved in the file as wxMaxima saves it (Phase 3 step 11, `panels-basics`). A status bar: Maxima's own messages (`wxstatusbar`, start-up problems) on the left; on the right a clock while Maxima works (questions included) and its CPU use, sampled each second over Maxima's process group as wxMaxima polls its child, then "Last evaluation: 5.0 s" (Phase 3 step 11). Values are text, not 2D math; no network-activity light | partial | math values: later |
| Table of contents | A sidebar of the worksheet's headings | View › Contents (⌘⌥1): the headings, indented by level, the section of the focused cell marked, folded ones marked; a click goes to the heading and unfolds what hides it (Phase 3 step 11, `panels-basics`). No dragging sections to reorder | done | reordering: later |
| Help | Topic names, the HTML manual | Help › Look Up in Maxima Manual (F1, wxMaxima's key) or the editor's context menu: the name or operator at the caret (or the selection) in a side panel, ⌘⌥0 shows or hides it. The text manual, what `describe` prints, read by Maxima's own index (`macsima.lisp`): every exact match without `describe`'s question (`diff` has three), prose rewrapped to the panel, call forms and examples in monospace, the manual's references as links, related topics, Back, a search field. Waits while Maxima is busy or asking (Phase 3 step 10, `help-basics`). Homebrew's Maxima has no HTML manual pages, so no HTML manual (agreed 2026-10-20); no `??` inexact search beyond the related list; no help for a name picked in the completion list | partial | HTML manual: not planned |
| Export and tooling | HTML, LaTeX, `.mac`, `.wxm` export, undo, search, diff viewer | Undo for cell insert, delete, type changes and typing (also after a cell scrolled away). Find and Replace across every cell's input (Phase 3 step 3). No export, no diff. | partial | 3 |
| Settings | Maxima and gnuplot paths, display options, `wxmaxima-init` | The Maxima path. | partial | 3 |
