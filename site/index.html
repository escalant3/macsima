Macsima

A native Mac app for Maxima, the computer algebra system. It opens and saves wxMaxima worksheets.

Download Macsima

macOS 26 or later on Apple silicon · Release notes · All releases

Install

  1. Install Maxima and gnuplot with Homebrew: brew install maxima gnuplot
  2. Open the DMG and drag Macsima to Applications.
  3. Open Macsima. It updates itself: Macsima › Check for Updates…

If Maxima or gnuplot live somewhere else, set their paths in Macsima › Settings.

Why Macsima

A native Mac app

Built with SwiftUI and AppKit: native windows, menus, keyboard shortcuts, Find and Replace, undo, dark mode.

Typeset math

Results are shown as proper 2D math, sharp on Retina displays. Long results break across lines.

wxMaxima compatible

Reads and writes .wxmx and .wxm. Anything it can't show yet is kept and saved back unchanged.

Few dependencies

Just Maxima and gnuplot. No wxWidgets, no extra toolkits.
